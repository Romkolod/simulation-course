### Базовый датчик случайных чисел

**Задание:**
- реализовать базовый датчик случайных чисел;
- вычислить выборочные среднее и дисперсию:
  - для реализованного датчика;
  - для встроенного генератора языка программирования;
- размер выборки — **100 000 значений**;
- сравнить результаты с теоретическими;
- сделать вывод.


ВЫВОД: 1) Линейный генератор работает корректно, его M(0.499394) и D(0.083266) совпали с теоретическими значениями M(0.500000) и D(0.083333) с небольшой погрешностью (0.000606) для M и (0.000067) для D. 2) Сравнение со встроенным генератором показало, что они оба обеспечивают примерно одинаковую точность. 3) Действие закона больших чисел наглядно демонстрируется на большой выборке
